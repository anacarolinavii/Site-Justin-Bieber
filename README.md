 Site Oficial — Justin Bieber

olaa! Este projeto foi desenvolvido com muito carinho como parte dos meus estudos no **1º período de Sistemas de Informação na PUC Minas**. 
A ideia principal foi tirar do papel um site moderno, responsivo e totalmente interativo dedicado ao Justin Bieber(ele é o meu cantor favorito desde criança), unindo um visual minimalista com boas práticas de programação frontend.

Nome: Ana Carolina Almeida Viana
Curso:Sistemas de Informação (1º Período)
Faculdade:PUC Minas

Para construir o site, utilizei as tecnologias que aprendi e pratiquei ao longo das aulas:
HTML5:Para estruturar toda a página de forma semântica.
CSS3 & Bootstrap 5:Para garantir a estilização (mantendo aquela vibe monocromática e estilosa) e a responsividade em qualquer tela.
JavaScript: ele que carrega os dados dinamicamente, faz o slider de imagens rodar sozinho, gerencia o menu mobile e abre os modais de detalhes.
Google Fonts: Usando a fonte Montserrat para dar um toque mais limpo e profissional, uso bastante no canva.

Slider dinâmico: Um carrossel na página inicial que destaca os principais momentos e turnês, com controle automático e navegação manual por botões ou bolinhas.
Conteúdo em formato JSON:Em vez de deixar tudo travado no HTML, os álbuns e as músicas são renderizados de forma inteligente através de uma estrutura de dados em JavaScript.
Modals interativos:Clicou em um álbum ou música? Abre um painel detalhado contando mais sobre ele.
Totalmente Responsivo: Seja no celular, no tablet ou no computador, o layout se adapta perfeitamente graças ao Bootstrap.
Newsletter: Um formulário com validação simples e feedback visual para quem quiser se inscrever nas novidades.
